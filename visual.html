Импорт HTML

Вставьте код блока T123, фрагмент страницы или загрузите HTML-файл

Для T123 рекомендуется импортировать самодостаточный фрагмент: HTML, при необходимости <style> и <script>. Внешние ссылки на CSS и JS сохраняются в итоговом коде.
Файл обрабатывается локально в браузере. Для надёжного импорта используйте HTML со встроенными стилями либо внешними абсолютными ссылками.
