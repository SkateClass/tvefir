Импорт HTML

Для блока T123 лучше вставлять самодостаточный фрагмент: HTML, при необходимости <style> и <script>. Внешние CSS/JS по ссылкам сохранятся в экспортированном коде.

Файл будет прочитан локально в браузере. Внешние ресурсы по абсолютным ссылкам останутся в коде.

Экспорт для Tilda T123

Скопируйте код и вставьте его в блок T123 «HTML-код» в Tilda. Затем нажмите «Опубликовать» на странице Тильды.
