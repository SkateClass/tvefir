ЭФИР HOME — PWA-дополнение 2.1.1

Это дополнение к РАБОТАЮЩЕМУ пульту версии 2.1, не замена его логики.
ТВ-плеер и Code.gs обновлять не нужно. Таблицы не меняются.

АРХИТЕКТУРА
Новая стартовая страница efir-pwa.html открывает существующий
./efir-remote-home.html в полноразмерном iframe того же сайта.
Оригинальный HTML пульта не модифицируется: вход, PIN, URL, сортировка,
логотипы, предпросмотр, переключение и настройки остаются в нём.
Оболочка не добавляет опросов Apps Script. В iframe разрешены autoplay,
fullscreen, picture-in-picture и encrypted-media; ограничения браузера сохраняются.

ЧТО ЗАГРУЗИТЬ НА GITHUB
Распакуйте архив. Загрузите ВСЕ перечисленные файлы в ту же папку,
где уже находится действующий efir-remote-home.html:
• efir-pwa.html
• efir-manifest.webmanifest
• efir-pwa-sw.js
• efir-pwa-offline.html
• efir-logo.svg
• efir-icon-192.png
• efir-icon-512.png
• efir-icon-maskable-512.png
• efir-apple-touch-icon.png

ВАЖНО
• Существующий efir-remote-home.html НЕ удалять и НЕ заменять оболочкой.
• Не переименовывать efir-pwa.html в efir-remote-home.html — получится самовложение.
• Все относительные пути рассчитаны на одну папку.
• Через редактор GitHub загружайте распакованные файлы, не один ZIP.
• Прямая ссылка github.com/.../blob/... и file:// не подходят. Нужен GitHub Pages HTTPS.
• Если в папке уже есть service worker другого приложения с тем же scope,
  разверните комплект в отдельной папке, скопировав туда и оригинальный пульт.
• GitHub Pages по умолчанию не запрещает такой same-origin iframe.
  На другом хостинге заголовки frame-ancestors/X-Frame-Options могут блокировать его.

НОВАЯ ССЫЛКА ДЛЯ УСТАНОВКИ
https://ВАШ-ЛОГИН.github.io/РЕПОЗИТОРИЙ/efir-pwa.html
Если файлы лежат в подпапке, добавьте её в адрес.
Открывайте и устанавливайте именно efir-pwa.html, а не прежнюю страницу и не /exec.

УСТАНОВКА
1. После публикации GitHub Pages откройте новую ссылку на смартфоне/планшете.
2. Дождитесь обычного интерфейса пульта. Если есть сообщение, что он не найден,
   проверьте наличие efir-remote-home.html рядом со стартовой страницей.
3. В браузере, который поддерживает beforeinstallprompt, сверху появится кнопка
   «Установить». Нажмите и подтвердите системную установку.
4. Если кнопка «Как установить», она покажет инструкцию. Можно использовать
   меню браузера → «Установить приложение» / добавление на главный экран
   именно как веб-приложения, если браузер предлагает такой режим.
5. Закройте вкладку и откройте НОВУЮ иконку «ЭФИР» с главного экрана.

HUAWEI
Реальная поддержка PWA зависит от конкретного Huawei Browser/системы.
Не каждый пункт «На главный экран» означает установку PWA — это может быть
обычный ярлык с открытием адресной строки. Если после запуска иконки остаётся
панель браузера, проверьте доступность именно установки веб-приложения
либо воспользуйтесь совместимым браузером. Код не может заставить браузер,
не поддерживающий standalone-установку, скрывать свои панели.
На реальном планшете пользователя установка не проверялась.

IPHONE / IPAD
Откройте efir-pwa.html в Safari → Поделиться → На экран Домой.
Если есть переключатель «Открывать как веб-приложение», включите его.
Запускайте новую иконку. В зависимости от ОС установленное приложение
может использовать отдельное хранилище — тогда один раз войдите по PIN заново.

ЧТО ЗНАЧИТ STANDALONE
Манифест задаёт display: standalone. Поддерживающий браузер при запуске
установленной иконки открывает отдельное окно без адресной строки и вкладок.
Системная строка времени/заряда и системная навигация могут оставаться.
Это НЕ запрос Fullscreen API и НЕ изменение полного экрана на компьютере с ТВ.
При открытии обычной ссылки в браузере браузерные панели остаются — это нормально.

СОХРАНЕНИЕ ВХОДА
Оболочка и iframe размещаются на одном origin. Пульт продолжает пользоваться
своим localStorage, без копирования PIN и ключей. В обычном браузерном
контексте существующий вход доступен. ОС/браузер могут изолировать хранилище
установленного веб-приложения: в таком случае нужен один первоначальный вход.
Затем работает сохранение устройства из версии 2.1.
Очистка данных сайта или кнопка «Забыть устройство» по-прежнему удаляют доступ.

СЕТЬ И КЭШ
Service worker кэширует только перечисленные локальные файлы оболочки
и HTML пульта после успешной загрузки под его управлением.
Запросы Apps Script, PIN, сеансы, таблицы, видео и внешние логотипы каналов
не перехватываются и не кэшируются этим service worker.
Другие страницы, включая ТВ-плеер, также не обслуживаются им из кэша.
При нормальном интернете используется свежая сетевая версия HTML; кэш — резерв.
При недоступной сети после 8 секунд может быть использован сохранённый интерфейс.
Для переключения ПК, актуального каталога и предпросмотра нужен интернет.
Офлайн-загрузка интерфейса не означает офлайн-работу домашнего ТВ.
Первое открытие пульта обязательно выполняйте с интернетом.
После первого успешного открытия рекомендуется один раз обновить страницу:
это позволяет service worker гарантированно сохранить iframe пульта.

ОБНОВЛЕНИЯ
Для обновления логики пульта заменяйте efir-remote-home.html, как прежде.
Service worker использует network-first и не закрепляет старый HTML навсегда.
При обновлении самой оболочки меняйте имя CACHE в efir-pwa-sw.js.
Когда новая оболочка готова, появляется кнопка «Обновить». Она перезагрузит
приложение и закроет текущий предпросмотр. Данные localStorage не очищаются.
Service worker не хранит ваши ключи в CacheStorage.

ПРОВЕРКА
1. Сначала новая ссылка должна показать тот же пульт, каналы и состояние ПК.
2. Проверьте поиск, открытие/закрытие предпросмотра и отдельное переключение.
3. Установите приложение и откройте иконкой: проверьте отсутствие адресной строки.
4. Закройте/откройте приложение: проверьте сохранение входа.
5. Проверьте клавиатуру, поворот планшета и возврат из фона.
6. Отключите интернет: появится предупреждение; команды в таком режиме не работают.

ЛОКАЛЬНЫЕ ПРОВЕРКИ
Синтаксис launcher/SW проверен через node --check.
Манифест прочитан Chromium через Page.getAppManifest без ошибок.
Иконки PNG: 192, 512, 512 maskable, 180 Apple.
Service worker реально зарегистрирован в тесте на localhost, проверены
сохранение интерфейса, загрузка офлайн, общий localStorage iframe и страницы,
отсутствие кэширования тестовой страницы ТВ, отсутствие ошибок JS.
Вместо полного пульта использовался минимальный тестовый iframe с совместимыми
DOM-метками: реальные функции пульта, Apps Script и видеопотоки не проверялись.
Установка физической иконки/standalone на Huawei или iPhone не проверялась.
