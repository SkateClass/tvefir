Источник и качество

Источники дополняются из API и M3U. Можно импортировать JSON-пакет только с дополнительными каналами/источниками; существующие записи объединяются, а не заменяются. Метки региональных версий и требований специальных заголовков видны в списке; браузер не подделывает такие заголовки.

Расписание переключения каналов

Создавайте ежедневные действия: в указанное время ЭФИР автоматически включит выбранный канал. Приложение должно быть открыто, а устройство — не переведено в режим сна с остановкой браузера.

Добавляйте действия по очереди. Для каждого выберите время и канал. Каналы показаны в том же порядке, что и в категории «Все категории».

Восстановление трансляции

При зависании ЭФИР один раз перезапустит текущий источник, затем попробует остальные источники канала. Если все они не запустятся, можно автоматически перейти на резервный канал.

По умолчанию используется Россия 1, если канал присутствует в каталоге. При ручном выборе можно назначить другой канал.

Каталог и новые каналы

Кнопка обновления каталога (↻) в списке каналов собирает новые записи и адреса из IPTV-org API/M3U и Radio Browser, объединяет дубликаты и сохраняет ваши личные каналы. Полноценная проверка каждого потока выполняется при запуске, а не во время сбора каталога.

Поиск новых телеканалов и источников

Собрать кандидатов из открытого каталога IPTV-org. Сначала покажет, что найдено: новые каналы и дополнительные потоки для уже известных каналов. Нажмите «Добавить», чтобы сохранить нужное, или ×, чтобы убрать ненужное из текущего списка предложений.

Сохранить рабочие источники

На устройстве с рабочей версией 0.10 выполните «Экспорт настроек», затем импортируйте JSON здесь. Импорт объединяет адреса, а не заменяет их. Это единственный способ перенести именно ваши сохранённые рабочие источники: их нет в новом HTML автоматически.

Радиоподборки

В разделе «Радио» выберите Comedy Radio, хип-хоп/рэп (включая отдельную подборку США), джаз, соул, фанк, американское ретро, китайские или европейские станции. Арабоязычные станции отфильтрованы. Для иностранных жанров дополнительно выберите «Зарубежные». Каталог использует жанровые метки, страну и язык; это не заранее проверенные плейлисты. Новые страницы загружаются по кнопке. Ранее загруженное и избранное сохраняются.

Управление и производительность

Удерживайте ⠿ для перестановки. В горизонтальном режиме тяните влево/вправо, в вертикальном — вверх/вниз; Alt + стрелки работает с клавиатуры. Архив — с подтверждением. «Запомнить» закрепляет источник в избранном.

Один активный поток. Для HLS увеличен целевой буфер до 32–48 секунд с ограничением памяти; при длительной буферизации или фатальной ошибке плеер автоматически пробует следующий источник. Минимальное качество выбирается первым, более высокое можно включить вручную. Это снижает риск обрывов, но не может компенсировать слабый Wi‑Fi, перегруженный процессор или нестабильный сервер вещателя. На старом ПК закройте лишние вкладки и выберите минимальное качество.
