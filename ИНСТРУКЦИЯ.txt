ЭФИР — комплект только для ПУЛЬТА (версия 2.4)

Содержимое:
- efir-remote-home.html — страница пульта;
- efir-pult.webmanifest — данные для установки приложения;
- efir-pult-sw.js — сервисный worker;
- efir-pult-icon.svg — векторная иконка;
- efir-pult-icon-180.png — значок для iPhone/iPad;
- efir-pult-icon-192.png и efir-pult-icon-512.png — значки для Android и браузеров.

УСТАНОВКА В GITHUB
1. Откройте репозиторий SkateClass/tvefir.
2. В корне репозитория замените старый efir-remote-home.html файлом из этого комплекта.
3. Загрузите туда же все остальные пять файлов из комплекта. Именно в корень репозитория, рядом с HTML, не в отдельную папку.
4. Сохраните изменения (Commit changes). Подождите 1–3 минуты, пока GitHub Pages обновится.
5. Откройте https://skateclass.github.io/tvefir/efir-remote-home.html
6. На телефоне обновите страницу. Если пульт уже добавляли на главный экран, удалите старый ярлык и добавьте его заново через меню браузера.

ВАЖНО
- Комплект содержит только пульт. Файл ТВ-плеера не включён.
- Google Таблицу и Apps Script менять не нужно.
- Открывать пульт для установки нужно по HTTPS-ссылке GitHub Pages, не из локального HTML-файла и не из предпросмотра GitHub.
- На Android обычно: Chrome → ⋮ → «Установить приложение» или «Добавить на главный экран».
- На iPhone: Safari → Поделиться → «На экран Домой».
- После загрузки проверьте, что эти файлы доступны по адресам с префиксом https://skateclass.github.io/tvefir/.
